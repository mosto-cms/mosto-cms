Mosto CMS is distributed under the MIT license (see [LICENSE](LICENSE)).

This file lists third-party code that is **copied or adapted** into this repository, with its
copyright and license notice, as those licenses require. Packages used only as npm
dependencies keep their own license files and are not listed here.

## Copied or adapted code

None at this time.

The design of Mosto CMS was informed by studying other open-source projects (among them
Keystatic, TinaCMS, Decap CMS, Sveltia CMS, Puck, Payload and `@sanity/visual-editing`), but no
code from them is included. If that changes, the entry will be added here, with the original
copyright notice and license text (and, for Apache-2.0 code, its NOTICE file and a statement of
the changes made).
